# Riverside 同步版导出

用于从 Riverside 导出课代表立正的同步节目视频与配套音频。这是长期制作默认值；用户对当期明确指定其他设置时，按当期要求执行。

## 导出默认值

- **Smart layouts：开启并应用。** 双人节目使用智能布局；当前界面可见的选项为 `Smart style`／`Grid or participant cutaway`。单人智能切镜可以全屏。
- **Magic Audio：开启并应用。** 这是界面中标为 `Studio-quality sound` 的音频处理。核对所有参与者的节目音轨；尚未启用时先 Apply，并等待处理完成，再导出同步视频和配套音频。
- **双人分屏位置固定：孙煜征／课代表立正在左，嘉宾在右。** 按人物身份确认，不能只依赖轨道顺序、文件名或当前发言人。摄像头切换、设备重启、掉线重连或换轨后也保持相同位置。

每期都读取并核实 Smart layouts 与 Magic Audio 的实际状态为开启，不能用“点过按钮”代替应用成功。界面文案可能变化，以当次可见控件和保存后的预览为准；设置打不开或处理失败时如实记录，不能把未处理版本当作已符合默认值的交付。

## 画面与音频验收

1. 确认本期主持人、嘉宾以及各段轨道的人物对应关系；摄像头切换前后分别查看双人分屏，保持主持人左、嘉宾右。
2. 应用后复查开头、中段、结尾及所有换轨／重连边界。智能切镜的单人全屏可保留；回到分屏时位置仍须一致。
3. 抽听处理后的各人声轨，确认 Magic Audio 已实际生效，且没有明显吞字、异常静音或失真；视频和配套音频使用同一 edit 与时间基准。
4. 下载后核对实际成片的布局、声轨、时长与可播放性。已有字幕时，确认新成片与字幕仍共用原时间轴；若时间轴改变，先重新映射并通过字幕 QC。

## 交付记录

在当期工作区记录 Riverside edit、导出版本、两项处理的实际状态、人物左右位置及换轨边界的检查结果。返工保留原下载版本，并明确哪个版本是本次可用的同步交付；原始独立轨道继续作为源素材保留。

此默认值只约束同步版制作与导出；平台发布仍按对应发布流程执行。
